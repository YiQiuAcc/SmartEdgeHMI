# SmartEdgeHMI v1.2.1 维护与收尾清单

> 状态：未开始（2026-11-23 建立）
> 基线：v1.2.0（发布包 `SmartEdgeHMI-1.2.0-win-x64.zip`，SHA256 `0c1869d9…61e949`，构建提交 `1744cd2`，tag `v1.2.0`）
> 定位：维护版。只做缺陷修复、验证补全、发布工程与文档修正；不新增协议、云平台、OTA、设备管理后台，不做承重架构重构。
> 来源：v1.2.0 Release Notes §5、next-steps P1-04 / P1-05 / P2、release-checklist §10、README 文档核对。

## 1. 完成定义

v1.2.1 完成需同时满足：

- 下列 P0 / P1 项全部关闭，或有明确“转入下一版 / 接受风险”的结论。
- `dotnet build -c Release` 0 错误；`dotnet test` 全部通过（不少于 129）；`dotnet format --verify-no-changes` 退出码 0；CI 四步全绿。
- F-4 / F-6 在真实硬件上复跑通过；无法复跑时必须在 Release Notes 标注限制。
- 发布包、SHA256、tag、Release Notes、检查表指向同一版本。
- 不夹带新功能、新协议或无关重构。

## 6. 暂不处理 / 已接受

| 项 | 结论 |
| --- | --- |
| 心跳协议无鉴权 | 已接受：冒充者需与安装目录同路径；未来多用户/远程场景再评估 |
| 趋势查询耗时持平 | 不是缺陷：收益在内存分配；不宣称提速 |
| 低完整性目录写盘失败 | 环境限制，非产品缺陷；解压到普通用户可写目录即可 |
| 升级按 30 天保留清理旧遥测 | 策略行为，不是数据丢失；升级前备份或调整保留配置 |
| `v1.1.0` tag 不可编译 | 历史限制，已追溯；不修复旧 tag |
| 包未签名 | 已列入 V121-05；无证书时保留为已知问题 |

## 7. 建议执行顺序

1. V121-01 / V121-02（固件 + 上位机 + 模拟器 + 单测）。
2. V121-03 / V121-04（稳定性小修）。
3. 真机复跑 HW-04（F-4 / F-6）；有条件时跑完整六项矩阵。
4. V121-06 / V121-14 / V121-15（发布收尾与文档）。
5. V121-05（有证书时）。
6. 打包 → SHA256 → 检查表 → Release Notes → tag `v1.2.1` → Release 页。
7. P2 验证项按时间排入后续维护，不作为 v1.2.1 发布阻塞。
